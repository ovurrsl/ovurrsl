# Pair Programming

Credit everyone who worked on a commit with a `Co-Authored-By` trailer.

```text
feat: add stair mirror transform

Mirror turning and cut-back stairs in place.

Co-Authored-By: Jane Doe <jane@example.com>
```

**Why:** GitHub shows every co-author on the commit and counts it in their contribution graph. The trailer must be at the end of the message, after a blank line, with the email of the person's GitHub account.
